# KIM YONGJIN Portfolio

## GitHub에 올리는 방법

1. ZIP 파일을 우클릭합니다.
2. `모두 압축 풀기`를 누릅니다.
3. 압축을 푼 폴더 안의 아래 4개 파일을 전부 선택합니다.
   - index.html
   - style.css
   - script.js
   - README.md
4. GitHub 업로드 화면의 흰색 영역에 드래그합니다.
5. 아래 초록색 `Commit changes`를 누릅니다.
6. `Settings → Pages`
7. `Deploy from a branch`
8. Branch `main`, Folder `/ (root)`
9. `Save`
10. https://msuleu4-web.github.io 접속

ZIP 파일 자체가 아니라 압축 안의 4개 파일을 올리세요.
